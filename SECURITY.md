# Security Policy

## Supported versions

Security fixes are generally applied to the latest released version.

## Reporting a vulnerability

If you find a security or privacy vulnerability, please avoid posting sensitive exploit details publicly in a GitHub Issue. Contact the repository maintainer privately through the contact method listed on the maintainer's GitHub profile.

Please include:

- affected version;
- steps to reproduce;
- expected behavior;
- actual behavior;
- potential impact;
- screenshots or logs if they do not contain private information.

Do not include passwords, authentication tokens, course credentials, or other sensitive personal data.

## Scope

Examples of issues worth reporting include unexpected external network requests, unauthorized data access, privilege/permission expansion, credential exposure, or code that could execute outside the intended Coursera page scope.
