# Changelog

## 4.4.0 — Current baseline

- Added configurable main playback speed.
- Added configurable last-25% playback speed.
- Default main speed is 16×.
- Default last-25% speed is 2.5×.
- Added continuous native playback-rate enforcement to counter player resets.
- Added automatic playback for newly loaded paused videos.
- Added automatic clicking of visible, enabled in-video `Skip` buttons.
- Added automatic advancement when Coursera exposes the ready main `Go to next item` button.

## Previous development versions

The 4.x series evolved from the original video-speed and auto-advance prototype. Earlier ZIP builds are preserved outside the public source tree only as development artifacts; future public releases should use GitHub Releases and semantic versioning.
